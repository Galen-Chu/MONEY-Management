# 📱 真機驗證手冊 · Device Check(Expo Go / SQLite 路徑)

> 目的:host 端已由「真 SQLite 引擎整合測試」覆蓋 SQL 語法與遷移(`src/data/__tests__/sqlite.integration.test.ts`,
> better-sqlite3 轉接 expo-sqlite 介面);本清單補最後一哩——**裝置上的 expo-sqlite 實際行為**
> (開庫/WAL/檔案系統/分享面板/剪貼簿)。由維護者於實機執行,任一項失敗請記下錯誤橫幅文案與步驟回報。

## 前置

1. 電腦執行 `npx expo start`(native 模式,非 `--web`)。
2. 手機與電腦同一網段,iPhone 以 Expo Go 掃描 QR(CLI 按 `s` 切 iOS)。

## 檢查清單(逐一勾選)

| # | 項目 | 通過條件 |
|---|---|---|
| 1 | 七分頁渲染 | 今天/貸款/帳戶/統計/發票/資產/設定皆正常;設定頁切「深色」→ 全 App 即刻換膚、Status bar 變淺色字 |
| 2 | **SQLite 持久化** | 記一筆交易 → 完整關閉 Expo Go(上滑清除)→ 重開 → 交易仍在 |
| 3 | 各模組寫入 | 帳戶/貸款/資產+估值/發票/分類預算/定期 各建一筆 → 重開 → 全部仍在 |
| 4 | 備份 | 設定→匯出→系統分享面板出現且可存檔;還原→兩段確認→資料取代成功 |
| 5 | 通知貼上 | 複製任一刷卡簡訊 → 今天頁「貼上通知解析」→ 待確認卡出現(iOS 會跳剪貼簿存取提示,允許) |
| 6 | 舊資料遷移 | 若裝置曾有較早版本資料:直接開啟即自動升級 v1→v9,**無錯誤橫幅**、舊發票/交易完整 |
| 7 | (有 appID 時)載具 | 發票頁綁定載具+填 appID →「同步本期」→ 發票入列、同號同期去重 |

## 回報格式

失敗項:步驟重現 → 預期 vs 實際(錯誤橫幅文案/畫面截圖)。全數通過:回報「DEVICE-CHECK 全過」即可歸檔本項。
